# מערכת ניהול תורים - סטודיו פילאטיס וספינינג

- `server/` - API ב-Node.js (Express + MongoDB/Mongoose)
- `client/` - React (Vite + React Router)

## הפעלה בפיתוח

שני טרמינלים:

```bash
cd server
npm install
npm run dev        # http://localhost:5000
```

```bash
cd client
npm install
npm run dev        # http://localhost:5173
```

אם לא מוגדר `MONGO_URI`, השרת מרים MongoDB מקומי בעצמו (הנתונים נשמרים ב-`server/.data`).
בהרצה הראשונה הוא מוריד את MongoDB (כמה דקות) וממלא נתוני דוגמה.
`npm run seed` (כשהשרת כבוי) מאפס את המסד לנתוני הדוגמה.

| מתאמנת | dana@studio.com | 050-2345678 | מנוי חודשי 8 + 2 השלמות |

השיעור הראשון של פילאטיס בשבוע הבא מלא (7/7), כדי שאפשר יהיה לנסות את רשימת ההמתנה.

### כניסה בטלפון
`SMS_PROVIDER=console` (ברירת המחדל): הקוד מודפס בלוג של השרת ומוצג גם בחלון הכניסה (בפיתוח בלבד).
לחיבור ספק אמיתי מוסיפים פונקציה ב-`server/src/services/sms.js`.

## הגדרות (`server/.env`, ראו `.env.example`)

| משתנה | תיאור |
|---|---|
| `MONGO_URI` | כתובת MongoDB (למשל Atlas). ריק = מקומי |
| `JWT_SECRET` | חובה בייצור |
| `SMS_PROVIDER` | `console` |
| `PORT` | ברירת מחדל 5000 |

מדיניות הסטודיו (24 שעות לביטול, 28 ימים קדימה לרישום, 7 מקומות) - ב-`server/src/config.js`.

## מה המנהלת יכולה לעשות

- **מתאמנות:** הוספה, עריכה, השבתה, איפוס סיסמה, הגדרת מנוי ותוקף.
- **כרטיס מתאמנת** (לחיצה על השם): הוספה מהירה של ניקובים / שיעורי השלמה (+ הערה, או מינוס להורדה),
  שיעורים קרובים עם ביטול (עם / בלי החזר), היסטוריית שיעורים והיסטוריית שינויים ביתרה.
- **בלוח השיעורים**, לחיצה על שיעור: רישום ידני של מתאמנת (עם / בלי חיוב), הסרה (עם / בלי החזר),
  סימון נוכחות, הסרה מרשימת המתנה, עריכת השיעור הבודד (שעה, מדריכה, קיבולת), ביטול השיעור לכולן והחזרת שיעור שבוטל.
- **"+ שיעור חד-פעמי"** בכל יום בלוח - שיעור מיוחד מחוץ למערכת הקבועה.
- **מערכת שעות קבועה, חגים ודוחות** - בלשונית "ניהול".

## כללים עסקיים

- **רישום** מוריד ניקוב / שיעור מהמכסה החודשית (ואם נגמרה - שיעור השלמה).
- **שיעור מלא** - הצטרפות לרשימת המתנה, בלי חיוב.
- **ביטול מעל 24 שעות** - החזר ליתרה, והראשונה ברשימת ההמתנה מקודמת אוטומטית (מחויבת ומקבלת התראה).
  אם אין לה יתרה - היא מקבלת התראה ועוברים לבאה בתור.
- **ביטול פחות מ-24 שעות** - נחסם (רק המנהלת יכולה להסיר).
- **מנוי חודשי** מחושב לפי חודש קלנדרי של תאריך השיעור.
- **חג** - מבטל את שיעורי היום, מחזיר יתרה ושולח התראה. מחיקת החג מחזירה את השיעורים.
- **שינוי במערכת הקבועה** - חל על השיעורים העתידיים; נרשמות מקבלות התראה על שינוי שעה.
- כל הבדיקות נעשות בשרת. הרישום אטומי, כך שלא ייתכן 8/7 גם בהרשמה בו-זמנית.
- מתאמנות רואות שמות של אחרות בקיצור ("חני כ."); המנהלת רואה שמות מלאים וטלפונים.
- נדרשת הצהרת בריאות לפני רישום ראשון.

## ייצור

```bash
cd client && npm run build
cd ../server && NODE_ENV=production npm start
```
השרת מגיש גם את `client/dist`.
